2 结论摘要

29执行用例
29通过（含 2 项回归复验）
4缺陷（1 个 P2 权限绕过）
4观察 / 可读性项
6环境存量项

核心结论

  1. clc → ign 远程交付链路在浏览器侧端到端成立：本次在 O-CLC 界面实发一次安装（TSK-20261006-0007，执行位置=远程执行机），35 秒内 7 个步骤逐条经点火中心交付门面受理并回执（TSK-20261006-0040~0046），成功后主控入口、凭据标识与集群生命周期状态由本域自动回写，全程无人工干预。
  2. 结论判定 INV-29（PLAY RECAP 优先于退出码）在界面可证：成功例（exit 0 + failed=0）与失败例（exit 1 + failed=1）判定依据均落 剧本汇总判定（优先于退出码）；活体 7 步全部走该口径。运行观测 c6 分布：EXIT_CODE 35 / PLAY_RECAP 2 / TRACE_LOST 2（采样时点，活体后 PLAY_RECAP +7）。
  3. 取消与撤销语义双向闭合：clc 侧「未执行即取消」+ INV-46 远端撤销引用（TSK-20261006-0036）+ R-15「取消不是回滚」留痕；ign 侧执行位留下 exit -15、终态 CANCELLED、耗时 39 000 ms（宽限期内 SIGTERM 收口）。
  4. 治理拒绝（R-12/R-13）在界面留痕可查：含节点地址注入 10.0.0.11;rm -rf / 被格式白名单拒绝、DESTROY/ADD_NODE 作为执行动作码越域拒绝、步骤编码 NEW 越出 01~07 参数域拒绝，共 6 条治理拒绝，均不与执行结论混计。
  5. 本轮修复项回归通过：O-IGN「运行观测」在缺 ign:FUNC-30 读权限时不再把统计卡整体打空（改为参数块降级提示）；opsadmin 全权视角参数表 11 项 REF-* 正常渲染。
  6. 唯一 P2 缺陷是新发现的接口越权：GET /api/v1/ign/stats（FUNC-29）在响应体里附带了完整运行参数集合，绕过 GET /api/v1/ign/params（FUNC-30）的读门禁。界面不显示，但数据可取，属权限口径缺口，建议上线前修掉。
判定口径：本报告只认定"界面与接口可观测事实"。凡依赖真机 kubeasz/ansible 的效果性结论（集群是否真的装成）由上游 O-CLC 与真实执行位承担，本次夹具不产出该类结论（定性一 ②）。

踩点备忘（本次同样复现）

  • 侧栏 SPA 菜单无 <a href>，自动化需先点 submenu 标题再点子项；直连路由可用（守卫在登录态下放行）。
  • antd 两汉字按钮会插空格（详情 → 可及名「详 情」），选择器须用 /详\s*情/；同理 查 询、确 定、刷 新。
  • antd 密码框同为 role=textbox，必须按可及名取字段，不能用 nth()；登录按钮存在动画导致的 "element is not stable"，用验证码位 press('Enter') 触发表单提交。
  • antd v6 模态框外层为 .ant-modal-wrap，.ant-modal-content 可能不存在，定位选择器应以 wrap 为作用域。
  • 列表数据键为 data.list；会话令牌 localStorage 键 cp_token（Bearer）。
  • localStorage / document 只能在 page.evaluate 内访问。
