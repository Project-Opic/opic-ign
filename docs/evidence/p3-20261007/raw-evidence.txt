== [F] Q-73 判据实测证据 ==
1) 交付配置标记 dns_domain = cluster.local（REF-19 生效值）
2) 探针 Pod 内 nslookup kubernetes.default.svc.cluster.local -> 10.68.0.1（集群内后缀实为 cluster.local）
3) 台账 clc_cluster.cluster_dns_domain = p3-lab.local，生成的 kubeconfig server = https://172.28.0.12:6443（走 master IP）
4) 节点上 api.p3-lab.local 不可解析（/etc/hosts 无条目）
=> 结论：集群内 DNS 后缀与上游登记的访问端点域名不同源。
